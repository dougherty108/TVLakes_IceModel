# Figures

PNG copies (300 dpi) of every plot in the two report R Markdown files. Each
report writes its plots here automatically when knitted, overwriting the
previous versions. File names come from the chunk that makes the plot.

## Antarctica_to_Rockies/  (Antarctica_to_Rockies_Comparison_Presentation.Rmd)

| File | Plot |
|---|---|
| all-lakes-1 | Modelled vs observed ice thickness, all lakes |
| meas-timeseries-1 | Model against each measurement type (z_water, z_ice) |
| meas-resid-1 | Model residuals by measurement type |
| meas-freeboard-1 | Freeboard at each measurement |
| lake-levels-1 | Surveyed lake levels |
| albedo-compare-forcing-1 | Albedo forcing, blue box vs whole lake |
| albedo-compare-thickness-1 | Modelled thickness with each albedo source |
| albedo-compare-diff-1 | Thickness difference, whole lake − blue box |
| forcing-tabs-1 … 6 | Model input time series: 1 WLB, 2 ELB, 3 LH, 4 LF, 5 GL4, 6 LOC |
| forcing-compare-1 | Monthly climatology of the model inputs, all lakes |
| wlb-1, elb-1, lh-1, lf-1, gl4-1, loc-1 | Individual lake model plots |
| profile-heatmap-1 | Modelled ice temperature with depth through time |
| profile-seasonal-1 | Seasonal ice temperature profiles |
| flux-magnitude-1 | Flux magnitude across sites (mean \|flux\|, log scale) |
| flux-signed-1 | Energy sources and sinks at the ice surface |
| flux-seasonal-1 | Monthly flux climatology |
| flux-tabs-1 … 6 | Monthly fluxes per lake: 1 WLB, 2 ELB, 3 LH, 4 LF, 5 GL4, 6 LOC |
